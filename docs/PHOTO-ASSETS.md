# 写真素材の記録

## 競輪フィッティング その一

ユーザー提供の写真5枚を原本のまま `assets/keirin-set-01/` に保管。
ここは `public/` の外側なので、サイトの画像URLとして配信しません。
公開用に選んだ写真のみ `public/images/keirin/` に複製しています。
人物名、撮影日時、競輪場名、指導の効果や成果は推測して掲載していません。

| 1000042301.jpg | 詳細ページの写真セクション。青い自転車での乗車姿勢（HOMEは第2便のロードバイク写真へ差し替え）。  |

| 1000042299.jpg | 第1便反映時の詳細ページ上部ビジュアル。現在は第2便のバンク写真へ差し替え、候補素材として保管。   |
| 1000042297.jpg | 原本を保管。スマートフォンの操作UIと動画再生画面が写っているため、現在はサイトに掲載しない。     |

写真そのもののレタッチ・合成・生成による補完は行っていません。
乗車写真は全体が見える `object-fit: contain` で表示。バンク写真は表示枠に合わせてCSSでトリミングしています。
配信時はNext.js Imageのサイズ最適化を利用し、意味のあるaltを付けています。
写真のパス・寸法・alt・キャプションは `lib/photos.ts` で変更できます。

正式公開前に、写っている方の掲載同意と撮影・掲載権限を確認します。
今回の反映はローカルサイトのみで、本番公開はしていません。
