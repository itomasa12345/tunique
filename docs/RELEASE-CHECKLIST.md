# 公開前の確認事項

現状はローカル確認用。管理者の明示承認まで、本番公開・外部ホスティング・独自ドメイン接続は行わない。

## 素材・事業内容

- [ ] 添付された正式ロゴの原本SVG/透過PNGを配置し、仮の文字ロゴを差し替える。
- [ ] プロフィールは本人確認・使用許可済みの作業写真を反映済み。受領済みの競輪フィッティング写真を含め、撮影・掲載権限と写っている方の掲載同意を確認する。
- [ ] 経歴、所属歴、約12年間という期間、現行の相談業務を本人が確認する。
- [ ] 対面・オンライン・全国出張の提供条件、地域、日程調整方法、準備物、実施場所を確認する。
- [ ] 料金、未確認の実績・口コミ、保険代理店の宣伝、保険会社・商品名が掲載されていないことを最終確認する。

## ライフプラン相談

- [ ] 実際に行う業務の範囲と、情報提供・助言・募集等の境界を法令および所属先規程に照らして確認する。
- [ ] 必要な資格・登録・表示義務・説明義務・広告審査の有無を確認する。現状では資格等を推測して掲載していない。
- [ ] 所属先等の名称を掲載しない方針と、法令・所属先規程に基づく必須表示が両立するか確認する。必須の表示は省略しない。
- [ ] NISA・iDeCoなどの制度説明、個別相談の対応範囲、運用成果非保証の表現を確認する。
- [ ] 確認完了まで該当表示・相談受付機能を本番公開しない。
