# ロードバイクと競輪の説明の整理

## 根拠と状態

ユーザーから「現在のサイトは競輪メインに見える」と指摘があり、本人のInstagram投稿（ロードバイク7枚・競輪8枚）を提供いただいて改稿した。
スクリーンショット原本は `assets/instagram-road-01/`、`assets/instagram-road-02/`、`assets/instagram-keirin-01/`、`assets/instagram-keirin-02/` に保管。原本はGit・サイト配信対象外。

掲載文は `lib/fitting.ts` と `app/bike-fitting/page.tsx` に整理。資料のスクリーンショットをそのままサイトへ貼る構成にはしていない。

## ロードバイク・全7枚で確認したこと

1. 身体と自転車の関係を見直す。
2. 速さ・快適さなど目指す走りは人それぞれ。力みの少ない自然な動きと本人の感覚を確かめる。
3. サドルの高さ・前後、ハンドルの高さ・位置、クリートの向き・位置を調整する。0.25mmの違いでも感覚が変わることがある。
4. 「踏みやすい」「少し違和感がある」「動かしやすい」などの感覚が調整の手がかり。
5. 部分の数値だけを合わせず、身体の全身運動と自転車全体のバランスを見る。
6. なぜそのサドル高・クリート位置なのか、違和感を一つずつ見直す。
7. 長く乗っていることや何となくしっくりくることだけで判断せず、位置を選ぶ理由を知り、今後の走りを考える基準にする。

## 競輪・全8枚で確認したこと

1. 自転車の進み、踏みの軽さ、選手自身の感覚を大切にする。
2. 実際のペダリングを確認し、脚が軽く自然に進む位置を探す。
3. 踏み込む打点を高い位置につくり、そこから脚が自然に落ちていく感覚を見る。
4. サドル高とサン（クリート）を調整し、左右の脚の入り方と力を伝える位置を確認する。
5. サドルをこれ以上高くしない上限の目安をつくる。基準位置が競走での唯一の正解とは限らない。
6. 基準をそのまま使う選手も、自分で調整する選手もいる。高回転・限界まで踏み込む場面では、サドルを少し下げ、踏み心地が重くなっても合う選手がいる。練習・競走で確かめる。
7. 調整がうまくいかなければ戻れる位置を持ち、選手自身が判断し調整できることを重視する。
8. 感覚だけ・数値だけではなく、自転車の進みと本人の感覚をポジションの基準にする。

## サイトの構成

- HOMEにロードバイク・競輪それぞれの説明とリンクを追加。
- 詳細ページの冒頭に両者を同じ階層で選べる入口を配置。
- `/bike-fitting#road`：自然な全身の動き、力み、全体のバランス、0.25mmの一例、本人の感覚、位置を選ぶ理由、調整項目と流れ。
- `/bike-fitting#keirin`：打点、左右の脚の入り方、上限の目安、基準と実戦の違い、サドルを下げる選手の例、戻れる基準と調整の判断。
- 競輪場写真は競輪セクション内へ移動。それぞれに写真と相談導線を配置。
- FAQで両者の重点の違いと、競輪の調整後の考え方を説明。

## 表現上の扱い

- 本人の感覚や全体のバランスは共有する。ロードは軽さを見ない、競輪は全身を見ない、など排他的な説明はしない。
- 0.25mmは変化を感じることもある例。常にこの単位で調整する、必ず変化する等の保証にはしない。
- 打点を高くするという説明を、サドルを高くすればよいという指示に置き換えない。
- 左右差や違和感が必ずなくなる、痛み・張りが解消する等の表現はしない。
- 投稿中の「多くの方が変化に驚く」等を、未確認の顧客実績として追加しない。
- 料金、競走成績や出力の改善保証は追加しない。既存の医療行為ではない旨の注意書きを維持する。
