TUNIQUE WordPressテーマ 1.0.0

導入先：制作確認用 https://masakazu-ito.com/tunique-preview/

1. 新しく作った制作確認用WordPressにログイン。
2. 外観 → テーマ → 新しいテーマを追加 → テーマのアップロード。
3. ダウンロードしたZIPを解凍せずに選び、インストール → 有効化。
4. ツール → TUNIQUE 初期設定 → 制作確認用データを取り込む。
5. サイトを表示し、トップ、サービス、プロフィール、コラム3件を確認。

初期取り込みは「検索エンジンがインデックスしないようにする」が有効で、
サイトURL末尾が /tunique-preview の場合のみ実行可能です。
既存の個人ブログ側には入れないでください。

固定ページ7件を作成し、トップページを設定します。
投稿URLを既存サイトと同じ /columns/投稿名/ に変更します。
承認済みコラム3件はWordPressの投稿になり、写真3件はメディアへ登録されます。
本文内の写真とサービスページ写真はテーマに同梱しています。
写真のクレジットと元の画角を保ちます。
同じデータを再取り込みしても、編集済みの記事を上書きしません。
同じURLに別の記事・固定ページがあると、取り込みを中止します。
初期サンプル投稿はコラム一覧に表示しません。削除はしません。

新しい記事：投稿 → 新規追加。タイトル、本文、アイキャッチ画像を設定。
初期設定後は「コラム」カテゴリーが初期選択され、ホームと一覧に反映されます。
コラムカテゴリーを外した投稿は一覧に出ません。
固定ページは複雑なレイアウトを含むため、大きく編集する前にバックアップしてください。

お問い合わせ：初期状態は送信停止。ツール → TUNIQUE 初期設定で送信先を入力し、
受信テスト時のみ有効化できます。実際の受信確認と必要なSMTP設定は別途必要です。
本テーマは問い合わせ本文をデータベースに保存しません。
プライバシーポリシーはWordPress・ロリポップのメール送信に合わせています。
Netlify Formsへは送信しません。

本番切り替え前に：
・既存WordPressと制作確認用WordPressのファイル・DBをバックアップ。
・各ページの文章・料金・保険関連表現を確認。
・受信、返信、失敗時の表示、迷惑メール振り分けを実際にテスト。
・旧URLからの転送、https、canonical、サイトマップを確認。
・ドメインの切り替えと検索掲載再開は、確認後に別途実施。

このテーマを入れただけでは tunique.jp の接続先は変わりません。
検索掲載の無効設定は閲覧制限ではありません。制作URLを知る人は閲覧可能です。
アクセス解析・広告スクリプトは追加していません。
SQLiteはローカルテストにのみ使用し、配布物には含みません。
